Purpose & Users

Purpose

Replace manual logbooks, hand-written receipts, and phone-based order tracking with one clean desktop workflow.

Who it helps

Shop Staff — add orders, update status, notify customers.

Shop Owner — monitor daily revenue and completed orders at a glance.

The Problem

Manual tracking

Small shops rely on paper tickets and mental math, leading to lost orders and pricing mistakes.

No automatic updates

Customers have to call or walk back to check if their laundry is ready.

No record keeping

Owners cannot easily see how much they earned today, this week, or this month.

Our Solution

Automated ordering

Staff enter name, Gmail, and weight — the system calculates the total and prints a receipt instantly.

Live status tracking

Every order moves from Pending to Completed with a single click. Nothing gets forgotten.

Automatic notifications

When an order is marked Completed, an email is sent to the customer's Gmail automatically.

System Architecture

Application

Main GUI window and event controller. Handles all screens, buttons, and user input.

LaundryDatabase

Encapsulates all MySQL operations — CRUD for customers, orders, and users.

GmailService

Manages SMTP connection and sends completion notifications.

AuthService

Validates login credentials using SHA-256 hashed passwords.

Database Design

Three MySQL tables work together to keep the data clean and relational.

Customers

Stores reusable customer info — Name, Email.

Orders

Links to a Customer. Stores Weight, Rate, Total Price, Status, and timestamps.

Users

Stores hashed passwords for the login screen.

Relationship: One Customer can have many Orders  1 : N

Core Features — CRUD

Create

Add a new laundry order and calculate the total price instantly.

Read

Display a live list of Pending and Completed orders on the dashboard.

Update

Edit customer details or order weight, or mark the order Completed.

Delete

Remove an order with a confirmation prompt to prevent accidents.

Additional Features

Login Screen

Secure access with hashed passwords stored in MySQL.

Search / Filter

Filter orders by customer name, Gmail address, or order number.

Receipt Generation

Creates a .txt receipt file for every order automatically.

Dashboard Statistics

Live totals for orders, revenue, and per-status counts.

Automatic Email

Sends a completion notice to the customer's Gmail via SMTP.

Logout

Safe session exit back to the login screen.
